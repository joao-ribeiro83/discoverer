1. End User Layer の更新

このバージョンのDiscoverer Desktop Edition (4.1.36)は、Discoverer Administration Edition 4.1.36で作成または更新されたEULにのみ接続することができます。
 

2. スケジュールされているワークブックの移行

注意：スケジュールはバッチ処理として設定されています。移行できるのはバッチ処理の部分であり、結果セットの移行はできません。

End User Layerを Discoverer 3.1から Discoverer 4.1 のものに更新すると、Discoverer 3.1 でスケジュールしていたワークブックはDiscoverer4.1ではスケジュールされません。このワークブックのスケジュール情報を移行するには、別の処理が必要です。この移行処理は古いDiscoverer3.1のEnd User Layerを削除する前に行なわなければなりません。
移行は次の２段階の処理で行ないます。

2.1 バッチスケジュールの更新

注意 - このステップでは、Oracle DiscovererAdministration Edition 4.1.36 と共にインストールされるファイルを使用します。

これを行なうには、<Oracle Home>\discvr4フォルダ（例：c:\orant\DISCVR4）にある 'dis4sch.exe'  を実行します。

コマンドラインから次のパラメータを使用して起動します。
EUL_Schema_Username/EUL_Schema password@database_Connect _String  c:\Log_file_name

例：
c:\dis4sch myeul/myeul_password@mydbase c:\DiscvrSched.log

次のようなメッセージが表示されます。

> Connecting to EUL...
> Migrating Schedule workbook metadata...
> Schedule workbooks metadata migrated successfully.

エラーについてはログファイルを参照してください。(この場合 c:\DiscvrSched.log)
第一段階はこれで終了です。すべてのスケジュール情報は移行されました。
 

2.2 スケジュールされたワークブックを有効にする

この時点では、ワークブックのスケジュール詳細は移行されましたが有効にはなっていません。ワークブックをスケジュールしている各ユーザーは次の手順を実行する必要があります。

Discoverer 4.1 Desktop Edition にログオンします。
「キャンセル」をクリックしてワークブックウィザードを閉じます。
「ファイル」→「ワークブックの管理」→「スケジュールマネージャ」を選択します。
Discoverer 4.1 Desktop Edition が、自動的にスケジュールされたワークブックを有効にします。
処理が終了するまで待ってください。ユーザーによってスケジュールされたワークブックの数により時間がかかります。
もし再スケジュールに失敗したワークブックがあった場合(例えばワークブック数の制限に達したり、EUL上にアイテムが見つからなかったり)、ワークブックを再度スケジュールしてくださいというメッセージがリストに表示されます。

移行作業はこれで完了です。

3. 既知の問題と回避策

ここに、既知の問題点および回避策がある場合はその回避策をリストします。

3.1 Discoverer Desktop Edition を Windows 95 上で実行できない

Windows 95 のユーザーは、Winsock 2.0 をMicrosoftのウェブサイトからダウンロードする必要があります。
Windows Socket 2 Update

上記Winsock 2.0 のインストール後、ダイヤルアップネットワーク1.3アップグレードを適用します。
ダイヤルアップネットワーク1.3アップグレード

Windows 98 には関係がありませんのでご注意ください。
 

3.2 Required Support Files (RSF) の更新

Discoverer は RSF 8.0.6.0.0 をインストールしますが、次の問題を解決するためにはRSFを 8.0.6.1.1 以降に更新する必要があります。

1040536  NLS: ZHT16MSWIN950 character set conversion causes errors.
    Discoverer サーバーは、ZHT16MSWIN950キャラクタセットのデータベースに接続できない。
729977  NLS: "Date format not recognized" error occurs using date format mask
    英語以外の言語を使用している場合、日付型のデータでエラーがでる場合がある。 "データ書式が理解できませんでした(Data format not recognized)"とエラーが表示され、値リストが返されない。
770803  NLS: Linguistic sort causes unexpected results
    句読点を含むデータが格納されている場合、ソート結果で正しくない結果が返される場合がある。
