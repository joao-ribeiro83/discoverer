must not reopen a decision here without new evidence that contradicts the Evidence column.**

revisit) · `OPEN` (needs an answer before the dependent phase starts).

`research/legacy-analysis.md` · `ARCH` = `research/architecture-analysis.md` · `FORMULA` =
`research/formula-decoder-analysis.md` · `SEC` = `research/security-analysis.md` · `UX` =

## C. Joins, aggregation and the fan-trap guard

| ID | Decision | Alternatives | Reason | Evidence | Consequences | Status |
| -- | -------- | ------------ | ------ | -------- | ------------ | ------ |

| **D-032** | Replace the item-pair `joins` model with **folder-to-folder `joins` + `join_predicates` (1..n column pairs, each with an operator)**.
